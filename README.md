# team-store

## Разработка

Нужен Node.js 22.12+ и npm (проверено на Node.js 24).

```sh
npm ci
npm run dev
```

Откройте адрес, который Vite напечатает в терминале.

## Команды

- `npm run build` — проверка TypeScript и сборка в `dist`.
- `npm run preview` — просмотр собранного приложения.
- `npm run lint` — проверка ESLint.
- `npm run format` — форматирование Prettier.
- `npm run format:check` — проверка форматирования.
- `npm test` — однократный запуск Vitest. Пустой набор тестов допустим на этапе настройки.
- `npm run test:watch` — тесты в режиме наблюдения.

## Git-хуки и TDD

Husky устанавливает хуки автоматически при `npm ci` или `npm install`.
Перед коммитом запускается только lint-staged: ESLint и Prettier проверяют
добавленные в коммит файлы. Тесты перед коммитом не запускаются.
Перед push выполняется `npm test`: падающие тесты блокируют отправку.

Для TDD сначала сделайте коммит с падающим тестом, затем реализуйте функцию
и сделайте коммит с проходящим тестом. После этого отправьте оба коммита вместе.
Тесты размещайте в файлах `*.test.ts`; функции `describe`, `it` и `expect`
импортируйте из `vitest`.

Prettier не изменяет `package-lock.json` и `.github/`.
